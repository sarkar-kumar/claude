## 51.1 What Is an Analogy Question?

An **analogy** compares two pairs of words that share the **same relationship**. It is written in the form

**A : B :: C : D** — read as "A is to B as C is to D".

::: ex
- **Doctor : Hospital :: Teacher : School** — a doctor works in a hospital as a teacher works in a school.
- **Pen : Write :: Knife : Cut** — a pen is used to write as a knife is used to cut.
:::

In Bangladeshi exams (BCS, Bank, university admission), you are usually given the first pair and must choose the pair with the **same relationship** from options, or complete the second pair. Analogies were a famous part of the old SAT and GRE; today the same reasoning skill drives GRE Text Completion and Sentence Equivalence and GMAT Critical Reasoning.

## 51.2 The Method — "Make a Bridge Sentence"

1. **Find the exact relationship** in the first pair and express it in a **short, precise sentence** (a "bridge"): *A* **scalpel** *is a tool used by a* **surgeon**.
2. **Test each option** with the same sentence: *A* **brush** *is a tool used by a* **painter** ✔. *A* **pen** *is a tool used by a* **writer** ✔ — if more than one option fits, make your bridge **more specific**: *a cutting tool used by a surgeon* → *a* **chisel** *is a cutting tool used by a* **sculptor**.
3. **Keep the order**: if the first pair is *worker : tool*, the answer must also be *worker : tool*, not *tool : worker*.
4. **Check the part of speech**: noun–verb pairs must match noun–verb pairs.
5. **Beware of distractors** that are merely related in topic but not in relationship (*doctor : patient* is not the same as *doctor : hospital*).

## 51.4 Worked Examples

::: ex
- **Ornithologist : Birds ::** Entomologist : **Insects** — a specialist studies a subject.
- **Pen : Writer ::** Brush : **Painter** — tool : user.
- **Glove : Hand ::** Sock : **Foot** — covering : body part.
- **Ocean : Water ::** Desert : **Sand** — place : main component.
- **Hunger : Food ::** Thirst : **Water** — need : what satisfies it.
- **Mason : Wall ::** Author : **Book** — maker : product.
- **Chapter : Book ::** Act : **Play** — part : whole.
- **Bark : Dog ::** Neigh : **Horse** — sound : animal.
- **Gaggle : Geese ::** Pride : **Lions** — group : members.
- **Loquacious : Talk ::** Voracious : **Eat** — doing something excessively.
- **Penurious : Money ::** Ignorant : **Knowledge** — lacking.
- **Prologue : Play ::** Preface : **Book** — introductory part.
- **Telescope : Astronomer ::** Microscope : **Biologist** — instrument : user.
- **Seed : Tree ::** Egg : **Bird** — origin : developed form.
- **Rain : Drought ::** Food : **Famine** — the absence of one causes the other.
:::

::: gre
**SAT / GRE / GMAT Corner — Analogical Reasoning:** Although the GRE no longer prints "A : B :: C : D" questions, its Reading and Critical Reasoning sections constantly ask you to find **parallel reasoning** — an argument with the same structure as another — which is analogy thinking at the level of sentences. The bridge-sentence technique (state the relationship precisely, then test each choice) works equally well there.
:::
