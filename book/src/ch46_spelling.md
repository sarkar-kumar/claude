## 46.1 Why Spelling Matters

English spelling is famous for its irregularity: the same sound can be spelt in many ways (*see, sea, scene, receive, believe, machine, key*), and the same letters can be pronounced in many ways (*though, through, tough, cough, bough, thought*). Competitive exams in Bangladesh — BCS Preliminary, Bank, Primary teacher, admission tests — regularly include **"Which one is correctly spelt?"** questions, and spelling errors in written exams reduce marks. This chapter gives the **rules that work most of the time** and an extensive list of **commonly misspelt words**.

## 46.2 Rule 1 — *i* before *e*, except after *c*

::: rule
**"I before E, except after C, or when sounded like A as in *neighbour* and *weigh*."**
:::

| Pattern | Examples |
|---|---|
| **ie** (usual) | believe, achieve, relieve, grief, chief, field, piece, niece, siege, shield, yield, priest, fierce, pierce, brief, thief |
| **ei** after **c** | receive, deceive, conceive, perceive, ceiling, receipt, conceit, deceit |
| **ei** sounding like **ay** | neighbour, weigh, weight, eight, freight, vein, reign, rein, sleigh, heir |
| **Exceptions** | either, neither, seize, weird, leisure, foreign, forfeit, height, their, protein, caffeine, counterfeit, sovereign, science, species, ancient, efficient, sufficient, society, conscience, financier |

## 46.3 Rule 2 — Doubling the Final Consonant

::: rule
Double the final consonant before a suffix beginning with a vowel (*-ed, -ing, -er, -est, -able*) when **all three** conditions are true:

1. the word ends in **one consonant**,
2. preceded by **one vowel**,
3. the word has **one syllable**, or the **stress falls on the last syllable**.
:::

| Doubled | Not doubled (and why) |
|---|---|
| stop → stopped, stopping | visit → visited (stress on 1st syllable) |
| run → running, runner | open → opened, opening |
| big → bigger, biggest | benefit → benefited |
| begin → beginning, beginner | target → targeted |
| prefer → preferred, preferring | prefer → **preference** (stress moves: *PREF-er-ence*) |
| occur → occurred, occurrence | offer → offered |
| admit → admitted, admittance | happen → happened |
| commit → committed, committee | develop → developed (✘ developped) |
| control → controlled | limit → limited |
| regret → regretted, regrettable | look → looked (two vowels) |
| refer → referred, referral | rain → rained (two vowels) |
| forget → forgetting, forgettable | help → helped (two consonants) |
| equip → equipped | budget → budgeted |
| transfer → transferred | focus → focused (also focussed in BrE) |

::: note
**British English** doubles a final **l** after a single vowel regardless of stress: *travel → travelled, traveller; cancel → cancelled; quarrel → quarrelled; label → labelled; model → modelling; marvel → marvellous; jewel → jeweller.* **American English** does not: *traveled, canceled, jeweler.* Also BrE *fulfil, enrol, skilful, wilful, instalment* vs AmE *fulfill, enroll, skillful, willful, installment.*
:::

## 46.4 Rule 3 — Dropping the Silent *e*

::: rule
Drop the final silent **e** before a suffix beginning with a **vowel**; keep it before a suffix beginning with a **consonant**.
:::

| Drop *e* (vowel suffix) | Keep *e* (consonant suffix) |
|---|---|
| hope → hoping | hope → hopeful |
| write → writing | care → careful, careless |
| come → coming | use → useful, useless |
| love → loving, lovable | love → lovely |
| move → movable | move → movement |
| desire → desirable | state → statement |
| believe → believable | sincere → sincerely |
| arrive → arrival | complete → completely |
| fame → famous | safe → safety |
| imagine → imagination | excite → excitement |

**Exceptions:**

- Keep the *e* after **soft c** or **soft g** before *-able / -ous*: *noticeable, manageable, changeable, peaceable, serviceable, courageous, outrageous, advantageous.*
- Keep *e* to avoid confusion: *dyeing* (colouring) vs *dying* (death); *singeing* vs *singing*; *shoeing, hoeing, canoeing.*
- Drop *e* before a consonant suffix in: *argue → argument, true → truly, due → duly, whole → wholly, judge → judgment* (BrE also *judgement*), *acknowledge → acknowledgment / acknowledgement, awe → awful, nine → ninth.*
- *-ee, -oe, -ye* keep *e*: *agreeing, seeing, fleeing, toeing, eyeing.*
- *mile → mileage*, *line → lineage*.

## 46.5 Rule 4 — Changing *y* to *i*

::: rule
When a word ends in **consonant + y**, change *y* to **i** before any suffix **except -ing** (and *-ish*). When it ends in **vowel + y**, keep the *y*.
:::

| Consonant + y → i | Keep y |
|---|---|
| happy → happiness, happily, happier | play → played, player, playful |
| carry → carried, carrier, carriage | enjoy → enjoyment |
| beauty → beautiful | obey → obeyed |
| try → tried, trial (but *trying*) | study → studying |
| busy → business, busily | cry → crying |
| marry → married, marriage | key → keys |
| apply → applied, appliance | annoy → annoyance |
| ready → readily | destroy → destroyer |
| merry → merriment | convey → conveyance |
| lonely → loneliness | |

**Exceptions:** *pay → paid, say → said, lay → laid* (vowel + y → *i*); *day → daily; gay → gaily; dry → dryness, dryly / drily; shy → shyly, shyness; sly → slyly; spy → spying.*

## 46.6 Rule 5 — Prefixes Never Change the Root

Adding a prefix does **not** change the spelling of the root, so double letters appear when the prefix ends with the same letter the root begins with:

*dis + satisfied = dissatisfied, mis + spell = misspell, un + necessary = unnecessary, im + mortal = immortal, il + legal = illegal, ir + regular = irregular, inter + related = interrelated, over + rule = overrule, re + enter = re-enter.*

Compare: *dis + appear = disappear* (one *s*), *dis + appoint = disappoint*, *mis + take = mistake*, *un + able = unable*.

## 46.7 Rule 6 — Suffixes Beginning with a Consonant

Simply add them; the root stays the same: *final + ly = finally, real + ly = really, accidental + ly = accidentally, mean + ness = meanness, sudden + ness = suddenness, cruel + ty = cruelty, govern + ment = government, environ + ment = environment, argu(e) + ment = argument.*

Words in **-ful** have only **one l**: *beautiful, careful, hopeful, faithful, useful, grateful, awful, skilful (BrE).* (✘ *beautifull*)

The suffix **-ly** after **-ful** gives **-fully**: *carefully, beautifully, hopefully.*

## 46.8 Rule 7 — *-able* or *-ible*?

- **-able** is used when the root is a **complete word** (or a word minus a final *e*): *acceptable, comfortable, dependable, readable, reasonable, available, valuable, desirable, lovable, advisable.*
- **-ible** is used when the root is **not a complete English word**: *audible, edible, visible, possible, horrible, terrible, plausible, feasible, legible, credible, eligible, tangible, compatible, susceptible.*
- Exceptions: *accessible, collapsible, convertible, contemptible, digestible, flexible, responsible, sensible, resistible* (complete roots + *-ible*); *probable, capable, vulnerable, formidable, inevitable, amiable* (incomplete roots + *-able*).

## 46.9 Rule 8 — *-ance / -ence*, *-ant / -ent*

There is no perfect rule, but these help:

- After **soft c** or **soft g** use **-ence / -ent**: *innocence, adolescence, convergence, intelligence, negligent.*
- After **hard c** or **hard g** use **-ance / -ant**: *significance, elegance, extravagant, arrogant.*
- If the related verb ends in **-ate**, use **-ance**: *tolerate → tolerance, dominate → dominance, radiate → radiance.*
- If the verb ends in **-ere** or **-er** (stressed), use **-ence**: *interfere → interference, refer → reference, prefer → preference, confer → conference, adhere → adherence, cohere → coherence.*

**Learn by heart:** *attendance, appearance, assistance, acceptance, allowance, balance, brilliance, guidance, maintenance, nuisance, perseverance, relevance, resistance, vigilance; absence, audience, coincidence, competence, confidence, consequence, convenience, correspondence, dependence, difference, evidence, existence, experience, independence, influence, obedience, occurrence, patience, permanence, persistence, presence, prominence, residence, reverence, silence.*

## 46.10 Rule 9 — *-ise / -ize* and *-yse / -yze*

- **British English** accepts both *-ise* and *-ize* (*organise / organize*); **American English** uses *-ize*. Be consistent.
- Some words **always** end in *-ise* (both varieties): *advertise, advise, arise, chastise, comprise, compromise, despise, devise, disguise, enterprise, exercise, franchise, improvise, revise, supervise, surmise, surprise, televise.*
- A few words are always spelt with **z** in both varieties: *capsize, seize, size, prize, baize.*
- **-yse** (BrE) / **-yze** (AmE): *analyse / analyze, paralyse / paralyze, catalyse / catalyze.*

## 46.11 Rule 10 — *-cede, -ceed, -sede*

- **-sede**: only **supersede**.
- **-ceed**: only **exceed, proceed, succeed**.
- **-cede**: all others — *accede, concede, intercede, precede, recede, secede.*
- Note: *proceed* but **procedure**; *exceed* but **excess**.

## 46.12 British vs American Spelling

| British English | American English |
|---|---|
| colour, honour, labour, favour, neighbour, behaviour, humour, rumour | color, honor, labor, favor, neighbor, behavior, humor, rumor |
| centre, theatre, metre, litre, fibre, calibre | center, theater, meter, liter, fiber, caliber |
| defence, offence, licence (n), practice (n) / practise (v) | defense, offense, license, practice (n & v) |
| organise, realise, recognise (or -ize) | organize, realize, recognize |
| analyse, paralyse | analyze, paralyze |
| travelled, cancelled, jewellery, counsellor | traveled, canceled, jewelry, counselor |
| catalogue, dialogue, monologue, analogue | catalog, dialog (often), monolog, analog |
| programme (TV), but computer program | program |
| cheque (bank), tyre, kerb, gaol (old) | check, tire, curb, jail |
| grey, plough, mould, smoulder | gray, plow, mold, smolder |
| aeroplane, anaemia, encyclopaedia, paediatric, mediaeval | airplane, anemia, encyclopedia, pediatric, medieval |

::: tip
**Exam Tip:** Bangladeshi exam keys follow **British spelling**. If an option shows the American form of a word (*color, center*), it is usually treated as correct only when no British form is offered — when in doubt, choose the British form.
:::

::: tip
**Memory tricks (mnemonics):**

- *ac**c**o**mm**odate* has room for **two c's and two m's**.
- *nece**ss**ary*: one **c**ollar and two **s**leeves.
- *sep**a**rate* — there is **a rat** in sep*a rat*e.
- *de**finite*** — it is **finite** (not *-ate*).
- *em**barr**a**ss*** — I turned **really red** and felt **so silly** (double r, double s).
- *ce**m**e**t**e**r**y* — all **e**'s: "**e**ee! I'm scared in a cemetery."
- *beli**e**ve* — never believe a **lie**.
- *rhythm* — **R**hythm **H**elps **Y**our **T**wo **H**ips **M**ove.
- *gover**n**ment* — governments **govern**.
- *Feb**r**uary* — say the first **r**.
:::

::: gre
**SAT / GRE / GMAT Corner:** None of these tests asks spelling questions directly, but the GRE Analytical Writing and the GMAT AWA are typed without spell-check, and misspellings weaken your score. More importantly, many GRE words are **near-homographs** whose meanings differ by one letter: *affect/effect, complement/compliment, discreet/discrete, elicit/illicit, eminent/imminent, principal/principle, prostate/prostrate, venal/venial, auger/augur, cannon/canon* — see Chapter 52.
:::
