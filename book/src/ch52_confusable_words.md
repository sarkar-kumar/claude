## 52.1 Why Words Are Confused

Some English words are confused because they **sound alike** (homophones: *principal / principle*), **look alike** (homographs and near-homographs: *eminent / imminent*), or have **related meanings** (*affect / effect, imply / infer*). Such pairs are tested heavily in BCS, Bank and admission exams ("Choose the correct word"), and they are a favourite source of traps in GRE vocabulary, SAT Writing ("Words in Context", "Usage") and GMAT Sentence Correction.

Each entry below gives the words, their meanings (with Bangla equivalents) and short examples.

## 52.2 The Master List (A–Z)

::: list
**Accept / Except / Expect** — *accept* [গ্রহণ করা]{.bn} = receive, agree to; *except* [ছাড়া]{.bn} = excluding; *expect* [প্রত্যাশা করা]{.bn} = look forward to. *I accept your offer. / All came except Rahim. / I expect him tomorrow.*

**Access / Excess** — *access* [প্রবেশাধিকার]{.bn} = right of entry; *excess* [অতিরিক্ত]{.bn} = too much. *Access to education / an excess of sugar.*

**Adapt / Adopt / Adept** — *adapt* [খাপ খাওয়ানো]{.bn} = adjust; *adopt* [গ্রহণ করা; দত্তক নেওয়া]{.bn} = take up, take as one's own; *adept* [দক্ষ]{.bn} = skilled. *Adapt to the climate. / Adopt a child. / He is adept at painting.*

**Addition / Edition** — *addition* [যোগ]{.bn} = adding; *edition* [সংস্করণ]{.bn} = a version of a book.

**Adverse / Averse** — *adverse* [প্রতিকূল]{.bn} = unfavourable; *averse* [বিমুখ]{.bn} = unwilling. *Adverse weather / He is averse to hard work.*

**Advice / Advise** — *advice* (noun) [উপদেশ]{.bn}; *advise* (verb) [উপদেশ দেওয়া]{.bn}.

**Affect / Effect** — *affect* (verb) [প্রভাবিত করা]{.bn} = influence; *effect* (noun) [ফল, প্রভাব]{.bn} = result; *effect* (verb) = bring about. *Smoking affects health. / The effect of smoking. / The new manager effected many changes.*

**Altar / Alter** — *altar* [বেদি]{.bn} = holy table; *alter* [পরিবর্তন করা]{.bn} = change.

**Alternate / Alternative** — *alternate* [একান্তর]{.bn} = every other; *alternative* [বিকল্প]{.bn} = another choice. *He visits on alternate days. / There is no alternative.*

**Amoral / Immoral** — *amoral* [নৈতিকতা-নিরপেক্ষ]{.bn} = without moral sense; *immoral* [অনৈতিক]{.bn} = morally wrong.

**Angle / Angel** — *angle* [কোণ]{.bn}; *angel* [ফেরেশতা, দেবদূত]{.bn}.

**Antic / Antique** — *antic* [ভাঁড়ামি]{.bn} = foolish behaviour; *antique* [প্রাচীন বস্তু]{.bn} = old valuable object.

**Apposite / Opposite** — *apposite* [যথাযথ]{.bn} = suitable; *opposite* [বিপরীত]{.bn}.

**Artist / Artiste** — *artist* [শিল্পী]{.bn} = painter, sculptor; *artiste* [অভিনয়/সংগীতশিল্পী]{.bn} = performer.

**Ascent / Assent** — *ascent* [আরোহণ]{.bn} = climb; *assent* [সম্মতি]{.bn} = agreement. *The President gave his assent to the bill.*

**Assay / Essay** — *assay* [ধাতু পরীক্ষা]{.bn} = test metal; *essay* [প্রবন্ধ; প্রচেষ্টা]{.bn}.

**Auger / Augur** — *auger* [তুরপুন]{.bn} = boring tool; *augur* [পূর্বাভাস দেওয়া]{.bn} = foretell. *This augurs well for the future.*

**Aural / Oral** — *aural* [শ্রবণ-সংক্রান্ত]{.bn} = of hearing; *oral* [মৌখিক]{.bn} = spoken, of the mouth.

**Bail / Bale** — *bail* [জামিন]{.bn} = security for release; *bale* [গাঁট]{.bn} = bundle. *A bale of jute.*

**Bare / Bear** — *bare* [খালি, নগ্ন]{.bn}; *bear* [ভালুক; বহন করা]{.bn}.

**Berth / Birth** — *berth* [শয্যা (জাহাজ/ট্রেন)]{.bn}; *birth* [জন্ম]{.bn}.

**Breath / Breathe** — *breath* (noun) [শ্বাস]{.bn}; *breathe* (verb) [শ্বাস নেওয়া]{.bn}.

**Bridal / Bridle** — *bridal* [বিবাহ-সংক্রান্ত]{.bn}; *bridle* [লাগাম]{.bn}.

**Canon / Cannon** — *canon* [নীতি; প্রামাণ্য রচনাসমূহ]{.bn} = rule, accepted works; *cannon* [কামান]{.bn}.

**Canvas / Canvass** — *canvas* [ক্যানভাস কাপড়]{.bn}; *canvass* [ভোট চাওয়া]{.bn} = seek votes. *Candidates canvass door to door.*

**Capital / Capitol** — *capital* [রাজধানী; মূলধন]{.bn}; *Capitol* [মার্কিন কংগ্রেস ভবন]{.bn}.

**Complement / Compliment** — *complement* [পরিপূরক]{.bn} = something that completes; *compliment* [প্রশংসা]{.bn} = praise. *The wine complements the meal. / He paid me a compliment.*

**Comprehensible / Comprehensive** — *comprehensible* [বোধগম্য]{.bn}; *comprehensive* [ব্যাপক]{.bn} = complete.

**Confidant / Confident** — *confidant* [বিশ্বস্ত বন্ধু]{.bn}; *confident* [আত্মবিশ্বাসী]{.bn}.

**Conscience / Conscious** — *conscience* [বিবেক]{.bn}; *conscious* [সচেতন]{.bn}.

**Contemptible / Contemptuous** — *contemptible* [ঘৃণ্য]{.bn} = deserving contempt; *contemptuous* [অবজ্ঞাপূর্ণ]{.bn} = showing contempt.

**Continual / Continuous** — *continual* [বারবার ঘটে এমন]{.bn} = repeated with breaks; *continuous* [অবিরাম]{.bn} = without a break. *Continual interruptions / continuous rain.*

**Corps / Corpse** — *corps* (pronounced *kor*) [বাহিনী]{.bn}; *corpse* [মৃতদেহ]{.bn}.

**Council / Counsel** — *council* [পরিষদ]{.bn}; *counsel* [পরামর্শ; উকিল]{.bn}.

**Credible / Credulous / Creditable** — *credible* [বিশ্বাসযোগ্য]{.bn}; *credulous* [সহজবিশ্বাসী]{.bn}; *creditable* [প্রশংসনীয়]{.bn}.

**Dairy / Diary** — *dairy* [দুগ্ধখামার]{.bn}; *diary* [দিনলিপি]{.bn}.

**Weather / Whether** — *weather* [আবহাওয়া]{.bn}; *whether* [কিনা]{.bn}.

**Who's / Whose** — *who's* = who is / who has; *whose* (possessive).

**Wont / Won't** — *wont* [অভ্যস্ত]{.bn} (*as is his wont*); *won't* = will not.
:::

::: tip
**Exam Tip — the "top twenty" pairs:** *affect/effect, principal/principle, stationary/stationery, complement/compliment, eminent/imminent, elicit/illicit, ingenious/ingenuous, credible/credulous, discreet/discrete, disinterested/uninterested, economic/economical, historic/historical, imply/infer, lie/lay, loose/lose, adapt/adopt, council/counsel, venal/venial, sanguine/sanguinary, flaunt/flout.*
:::

::: gre
**SAT / GRE / GMAT Corner:** GRE answer choices deliberately include near look-alikes — *venal / venial*, *prodigal / prodigious*, *enervate / energise*, *noisome / noisy*, *restive / restful*, *fulsome / full*, *temerity / timidity*, *tortuous / torturous*. The GMAT tests *affect/effect*, *fewer/less*, *number/amount*, *like/as*, *whether/if*, *due to/because of*. When you meet such a choice, slow down: the test is checking **exact meaning**, not general familiarity.
:::
