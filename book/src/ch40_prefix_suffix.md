## 40.1 Roots, Prefixes and Suffixes

Most English words — especially the long, difficult words found in the GRE, SAT, GMAT and BCS vocabulary sections — are built from smaller parts:

- **Root (base):** the core part carrying the main meaning — *port* (carry) in *transport, export, portable*.
- **Prefix:** a part added **before** the root that changes its **meaning** — **un**happy, **re**write, **trans**port.
- **Suffix:** a part added **after** the root that usually changes its **part of speech** (and sometimes meaning) — happi**ness**, port**able**, teach**er**.

::: ex
- **un + believ + able** = unbelievable (not able to be believed)
- **in + vis + ible** = invisible (not able to be seen)
- **bene + fact + or** = benefactor (one who does good)
- **anti + bio + tic** = antibiotic (against life — kills bacteria)
:::

Knowing about 60 prefixes, 50 suffixes and 100 roots allows you to guess the meanings of **thousands** of words. This chapter lists the most useful ones.

## 40.2 Prefixes

### 40.2.1 Negative Prefixes (meaning *not / opposite / without*)

| Prefix | Meaning | Examples |
|---|---|---|
| **a-, an-** | not, without | atheist, amoral, apathy, anarchy, anonymous, asymmetry, atypical |
| **un-** | not, opposite of | unhappy, unable, unknown, unfair, undo, untie, unlock |
| **in-** | not | inactive, incorrect, invisible, insane, inaccurate, incapable |
| **im-** (before b, m, p) | not | impossible, immature, imbalance, impatient, impolite, immortal |
| **il-** (before l) | not | illegal, illiterate, illogical, illegible, illicit |
| **ir-** (before r) | not | irregular, irrelevant, irresponsible, irrational, irresistible |
| **dis-** | not, opposite, apart | dishonest, disagree, disappear, dislike, disobey, disconnect |
| **non-** | not | nonsense, non-violent, non-existent, nonstop, non-resident |
| **mis-** | wrongly, badly | misunderstand, misuse, mislead, misbehave, misfortune, misprint |
| **mal-** | badly, evil | malnutrition, malfunction, malpractice, malevolent, maltreat |
| **anti-** | against | antisocial, antibiotic, antidote, antiseptic, anticlockwise |
| **counter-** | against, opposite | counteract, counterattack, counterfeit, counterpart |
| **contra-** | against | contradict, contraband, contraceptive, contrary |
| **de-** | down, remove, reverse | decrease, deforest, defrost, devalue, decode, demotivate |
| **dys-** | bad, difficult | dysfunction, dyslexia, dysentery |

::: note
**Caution — not every *in-* is negative.** *Inflammable* = easily set on fire (same as *flammable*); *invaluable* = extremely valuable; *inhabit* = live in; *intense, inquire, income, inside, insight* — here *in-* means *in/into*. Similarly *unravel* and *ravel* can both mean "untangle".
:::

::: gre
**SAT / GRE / GMAT Corner — Decoding Unknown Words:** When you meet an unfamiliar GRE word, break it into parts. *Circumlocution* = *circum* (around) + *locu* (speak) → "talking around the point". *Malediction* = *male* (bad) + *dict* (say) → a curse. *Benevolent* = *bene* (good) + *vol* (wish) → kind. *Anachronism* = *ana* (against) + *chron* (time) → something out of its proper time. Roots will not always give the exact meaning (*pedagogue* has nothing to do with feet — Greek *paid-*, child), so use them as **clues**, not proofs, and confirm with context.
:::
