## 6.1 What Is Number?

**Number** is the form of a noun or pronoun that shows whether it refers to **one** or **more than one**.

- **Singular number** — one person or thing: *boy, book, child, I, he.*
- **Plural number** — more than one: *boys, books, children, we, they.*

Only **countable nouns** have both numbers. Uncountable nouns (Chapter 03) are used only in the singular. Number affects the choice of verb (*is/are, has/have*), determiner (*this/these, much/many*) and pronoun (*it/they*), so plural formation is basic to correctness.

## 6.2 Regular Plurals

### 6.2.1 Most nouns: add **-s**

*book → books, pen → pens, girl → girls, cat → cats, tree → trees, river → rivers.*

### 6.2.2 Nouns ending in **-s, -ss, -sh, -ch (soft), -x, -z**: add **-es**

*bus → buses, gas → gases, class → classes, glass → glasses, brush → brushes, dish → dishes, bench → benches, watch → watches, box → boxes, tax → taxes, fox → foxes, buzz → buzzes, quiz → quizzes.*

But *-ch* pronounced /k/ takes only **-s**: *stomach → stomachs, monarch → monarchs, epoch → epochs, patriarch → patriarchs.*

### 6.2.3 Nouns ending in consonant + **y**: change *y* to **i** and add **-es**

*baby → babies, lady → ladies, city → cities, army → armies, story → stories, fly → flies, country → countries, duty → duties.*

Nouns ending in **vowel + y** simply add **-s**: *boy → boys, day → days, key → keys, monkey → monkeys, toy → toys, valley → valleys, chimney → chimneys, journey → journeys, essay → essays.*

Proper nouns ending in *-y* add **-s**: *the two Marys, the Kennedys.*

### 6.2.4 Nouns ending in **-o**

| Add **-es** (mostly consonant + o, common words) | Add **-s** (vowel + o; short forms; foreign/musical words) |
|---|---|
| hero → heroes | radio → radios |
| potato → potatoes | studio → studios |
| tomato → tomatoes | bamboo → bamboos |
| mango → mangoes (also mangos) | zoo → zoos |
| buffalo → buffaloes | cuckoo → cuckoos |
| echo → echoes | photo → photos |
| volcano → volcanoes | piano → pianos |
| negro → negroes (dated) | kilo → kilos |
| cargo → cargoes | logo → logos |
| mosquito → mosquitoes | dynamo → dynamos |
| torpedo → torpedoes | solo → solos, soprano → sopranos |
| veto → vetoes | memo → memos, canto → cantos |
| motto → mottoes (also mottos) | ratio → ratios, portfolio → portfolios |

### 6.2.5 Nouns ending in **-f** or **-fe**: change to **-ves** (common group)

*leaf → leaves, loaf → loaves, life → lives, knife → knives, wife → wives, wolf → wolves, half → halves, calf → calves, shelf → shelves, thief → thieves, self → selves, sheaf → sheaves, elf → elves.*

But many simply add **-s**: *roof → roofs, chief → chiefs, proof → proofs, belief → beliefs, cliff → cliffs, gulf → gulfs, safe → safes, chef → chefs, grief → griefs, reef → reefs, handkerchief → handkerchiefs, dwarf → dwarfs, strife → strifes, serf → serfs.*

Both forms: *scarf → scarfs/scarves, wharf → wharfs/wharves, hoof → hoofs/hooves, dwarf → dwarfs/dwarves.*

## 6.3 Irregular Plurals

### 6.3.1 Change of inner vowel (mutation)

| Singular | Plural | Singular | Plural |
|---|---|---|---|
| man | men | foot | feet |
| woman | women | tooth | teeth |
| goose | geese | mouse | mice |
| louse | lice | dormouse | dormice |

Compounds follow the same rule: *Englishman → Englishmen, policeman → policemen, fireman → firemen, chairman → chairmen.* But *German → Germans, Roman → Romans, Norman → Normans, human → humans, talisman → talismans, Mussulman → Mussulmans* (because *-man* here is not the word "man").

### 6.3.2 Adding **-en / -ren**

*ox → oxen, child → children, brother → brethren* (= members of a religious society; normal plural *brothers*).

### 6.3.3 Same form in singular and plural

*sheep, deer, swine, fish (also fishes for species), aircraft, spacecraft, hovercraft, cod, salmon, trout, series, species, means, corps, headquarters, crossroads, gallows, offspring, yoke (of oxen), Chinese, Japanese, Swiss, Portuguese, Vietnamese, Bengali (people) → Bengalis.*

::: ex
- **A sheep** is grazing. / **Ten sheep** are grazing. (✘ sheeps)
- I saw **a deer** / **three deer**.
- This **series** is popular. / Both **series** are popular.
- **A means** of transport / Various **means** of transport.
:::

### 6.3.4 Nouns of number, measure, weight with a numeral before them

*dozen, score, hundred, thousand, million, gross, stone (weight), pair, head (of cattle), yoke, hundredweight* keep the singular form after a definite number:

::: ex
- **two dozen** eggs (✘ two dozens eggs), **three hundred** taka, **five thousand** people, **ten million** dollars, **four score** years (= 80), **two pair** of shoes (also two pairs), **fifty head** of cattle, **a ten-stone** man / He weighs **ten stone**.
- But without a number, the plural is used: **dozens of** eggs, **hundreds of** people, **thousands of** birds, **millions of** stars, **scores of** students.
:::

### 6.3.6 Plurals of compound nouns

**Rule 1:** In most compounds, the **principal (most important) word** takes the plural sign:

| Singular | Plural |
|---|---|
| commander-in-chief | commanders-in-chief |
| father-in-law | fathers-in-law |
| mother-in-law | mothers-in-law |
| son-in-law, daughter-in-law | sons-in-law, daughters-in-law |
| brother-in-law, sister-in-law | brothers-in-law, sisters-in-law |
| passer-by | passers-by |
| man-of-war | men-of-war |
| step-son | step-sons |
| court-martial | courts-martial (also court-martials) |
| attorney-general | attorneys-general |
| governor-general | governors-general |
| maid-servant | maid-servants |
| hanger-on | hangers-on |
| looker-on | lookers-on |
| runner-up | runners-up |
| coat-of-mail | coats-of-mail |
| editor-in-chief | editors-in-chief |
| lady-love | lady-loves |

**Rule 2:** When no word is a noun, or the compound is written as one word, the **last word** takes the plural sign: *forget-me-not → forget-me-nots, drawback → drawbacks, grown-up → grown-ups, go-between → go-betweens, take-off → take-offs, handful → handfuls, spoonful → spoonfuls* (or *spoonsful*), *cupful → cupfuls, mouthful → mouthfuls, breakdown → breakdowns.*

**Rule 3:** Compounds with *man/woman* as the first word pluralise **both** parts: *man-servant → men-servants, woman-doctor → women-doctors, woman-servant → women-servants, lady-doctor → lady-doctors* (only the second).

### 6.3.7 Plurals of letters, figures, signs and abbreviations

*Mind your p's and q's. / Dot your i's and cross your t's. / Two 5's (or 5s) / in the 1990s / three M.A.s (or M.A.'s) / MPs / PhDs / ifs and buts / dos and don'ts / yeses and noes.*

### 6.3.8 Plurals of proper nouns and titles

- *The two Rahims, the Khans, the Joneses.*
- Titles: *Mr. → Messrs. (Messrs. Rahman & Sons), Mrs. → Mmes. (rare), Miss → Misses (the Misses Smith / the Miss Smiths), Dr. → Drs.*

## 6.4 Nouns Used Only in the Plural

### 6.4.1 Things made of two parts

*trousers, pants, jeans, shorts, pyjamas, breeches, scissors, shears, tongs, pliers, pincers, spectacles, glasses, goggles, binoculars, bellows.*

::: ex
- My **spectacles are** broken. / **A pair of** spectacles **is** on the table.
- ✘ I bought **a scissor**. ✔ I bought **a pair of scissors**.
:::

### 6.4.2 Other "plural-only" nouns

*alms, amends, annals, archives, arrears, assets, belongings, clothes, congratulations, credentials, dregs, earnings, embers, environs, goods, lodgings, manners (= behaviour), means (= wealth), oats, odds, outskirts, premises, proceeds, regards, remains, riches, savings, shambles, spirits (= mood), stairs, surroundings, thanks, tidings, valuables, victuals, wages, whereabouts.*

### 6.4.3 Nouns always plural in meaning though singular in form

*cattle, poultry, vermin, people, police, gentry, clergy, peasantry, folk* — always a plural verb: *The* **police are** *investigating. The* **cattle are** *grazing.*

## 6.5 Nouns Plural in Form but Singular in Meaning

*news, mathematics, physics, economics, politics, ethics, statistics, civics, phonetics, measles, mumps, rickets, billiards, innings, gallows, summons (= a court order), the United States, the Philippines.*

::: ex
- **No news is** good news.
- **Measles is** a contagious disease.
- **Economics is** my major subject.
- The **summons was** issued yesterday. (plural: *summonses*)
:::

## 6.8 Collective Nouns and Number

A collective noun is singular in form but may take a singular or plural verb depending on the meaning (unit vs individuals). See Chapter 02 and Chapter 23.

::: ex
- The **team is** strong. (unit) / The **team are** taking their seats. (individuals)
- The **family is** large. / The **family are** at dinner. (BrE)
:::

## 6.10 Common Errors with Number

::: errs
1. ✘ The **sheeps** are grazing. ✔ The **sheep** are grazing.
2. ✘ I have **two dozens** pens. ✔ I have **two dozen** pens.
3. ✘ He gave me **a five hundreds taka** note. ✔ He gave me **a five-hundred-taka** note.
4. ✘ My **mother-in-laws** are kind. ✔ My **mothers-in-law** are kind.
5. ✘ The **criterias** are clear. ✔ The **criteria** are clear.
6. ✘ This **phenomena** is strange. ✔ This **phenomenon** is strange.
7. ✘ There are many **datas**. ✔ There are a lot of **data**.
8. ✘ The **passer-bys** stopped. ✔ The **passers-by** stopped.
9. ✘ He bought two **pair** shoes. ✔ He bought two **pairs of** shoes. (or *two pair of shoes*)
10. ✘ **Hundred of** people came. ✔ **Hundreds of** people came.
11. ✘ I saw **many deers**. ✔ I saw **many deer**.
12. ✘ The **thiefs** were caught. ✔ The **thieves** were caught.
13. ✘ He has two **wifes**. ✔ He has two **wives**.
14. ✘ The **chieves** met. ✔ The **chiefs** met.
15. ✘ The **potatos** are fresh. ✔ The **potatoes** are fresh.
16. ✘ The **radioes** are cheap. ✔ The **radios** are cheap.
17. ✘ Three **Englishmans** came. ✔ Three **Englishmen** came. / ✘ Three **Germen** ✔ Three **Germans**.
18. ✘ He has three **brother-in-laws**. ✔ He has three **brothers-in-law**.
19. ✘ The **crisises** deepened. ✔ The **crises** deepened.
20. ✘ He is a **ten-years** old boy. ✔ He is a **ten-year-old** boy.
21. ✘ The **headquarter** of the UN is in New York. ✔ The **headquarters** of the UN **is/are** in New York.
22. ✘ Please accept my **thank**. ✔ Please accept my **thanks**.
23. ✘ He lives in the **outskirt** of the town. ✔ He lives on the **outskirts** of the town.
24. ✘ He gave me **a good news**. ✔ He gave me **good news**.
25. ✘ All **the staffs** of the office were present. ✔ All **the staff** (members) of the office were present.
:::

::: gre
**SAT / GRE / GMAT Corner — Number Consistency:** GMAT and SAT items test whether a noun's number matches the noun it refers to. ✘ "Each applicant must submit an essay with **their applications**." ✔ "Each applicant must submit an essay with **his or her application**." Watch for **logical number**: ✘ "Both parents signed their consent on **their form**." ✔ "Both parents signed their consent on **their forms**." (each parent has a form). Be ready for Latin and Greek plurals in GRE reading passages too: *data, criteria, phenomena, strata, media.*
:::
