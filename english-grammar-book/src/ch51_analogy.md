## 51.1 What Is an Analogy?

An **analogy** is a comparison between **two pairs of words** that share the **same relationship**. It is written as:

**A : B :: C : D** — read as "*A is to B as C is to D*".

::: ex
- **Doctor : Hospital :: Teacher : School** — a doctor works in a hospital as a teacher works in a school.
- **Bird : Flock :: Cow : Herd** — a group of birds is a flock as a group of cows is a herd.
- **Hot : Cold :: Light : Dark** — opposites.
:::

Analogy questions appear regularly in **Bank recruitment tests** (especially private banks and Bangladesh Bank AD), some **BCS** and **university admission** papers, and in many international aptitude tests. The **GRE** and **SAT** formerly had analogy sections (removed in 2011 and 2005), but the **reasoning skill** they test — identifying the precise relationship between words — is still central to GRE Text Completion, Sentence Equivalence and Critical Reasoning.

## 51.2 How to Solve an Analogy: The Bridge Sentence Method

::: rule
1. **Form a precise "bridge" sentence** that links the first pair: *A doctor **works in** a hospital.*
2. **Apply the same sentence** to each answer pair: *A teacher **works in** a school* ✔ / *A patient **works in** a hospital* ✘.
3. If more than one pair fits, **make the bridge more specific**: *A doctor **treats patients in** a hospital* → *A teacher **teaches students in** a school*.
4. **Check the order and the part of speech.** *Doctor : Hospital* (person : place) cannot match *School : Teacher* (place : person) — the order is reversed.
5. **Beware of "associated" words** that share a topic but not the relationship: *Doctor : Hospital* does **not** match *Doctor : Nurse*.
:::

| **Part : Whole** | Page : Book | A is a part of B | Petal : Flower |
| **Whole : Part** | Car : Engine | B is part of A | Tree : Branch |

## 51.6 Typical Traps

1. **Reversed order:** *Hive : Bee* (home : animal) ≠ *Dog : Kennel* (animal : home).
2. **Same topic, different relation:** *Doctor : Medicine* (gives) ≠ *Doctor : Hospital* (works in).
3. **Wrong degree:** *Warm : Hot* (moderate : extreme) ≠ *Hot : Warm* (extreme : moderate).
4. **Too general a bridge:** "*A is related to B*" fits everything — make it specific.
5. **Part of speech mismatch:** *Run : Race* (verb : noun) ≠ *Runner : Race* (noun : noun).

## 51.7 Analogies in the SAT, GRE and GMAT

::: gre
Although analogy questions are no longer printed in the GRE and SAT, the **relationship-spotting skill** is essential:

- **GRE Text Completion:** the blank often stands in a relationship (synonym, contrast, cause–effect) to a clue word — the same thinking as an analogy.
- **GRE vocabulary** is often learnt through classic analogies: *laconic : words :: frugal : money*; *intrepid : fear*; *impecunious : money*; *apathetic : interest*; *placate : anger*; *mitigate : severity*; *corroborate : claim*; *exonerate : blame*.
- **GMAT Critical Reasoning** includes "parallel reasoning" questions — choosing an argument with the **same logical structure** as the given one, which is analogy applied to whole arguments.
:::
