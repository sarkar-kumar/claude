## 46.1 Why Spelling Is Tested

English spelling is notoriously irregular: *though, through, thorough, tough, cough* all end in *-ough* but sound different. Because of this, **"Choose the correctly spelt word"** is a regular MCQ in BCS Preliminary, Bank recruitment tests and university admission tests, and spelling mistakes cost marks in every written paper. The words tested are usually **commonly misspelt** ones such as *accommodation, committee, embarrass, millennium, occurrence, privilege, questionnaire*.

This chapter gives (1) the **main spelling rules**, (2) **British vs American** spellings, and (3) a large list of **commonly misspelt words** grouped by the type of trap.

## 46.2 The Main Spelling Rules

### 46.2.1 *i* before *e*, except after *c*

::: rule
Write ***ie*** when the sound is "ee" (*believe, chief*); write ***ei*** after ***c*** (*receive, ceiling*) and when the sound is "ay" (*neighbour, weigh*).
:::

| *ie* | *ei* after *c* | *ei* sounding "ay" | Exceptions to learn |
|---|---|---|---|
| believe, achieve, chief, field, grief, niece, piece, relief, siege, yield, brief, shield, priest, fierce | receive, receipt, ceiling, deceive, conceive, perceive, conceit, deceit | neighbour, weigh, weight, eight, vein, reign, sleigh, freight, beige | either, neither, seize, weird, leisure, foreign, height, heir, their, protein, caffeine, forfeit, sovereign, counterfeit, species, science, sufficient, ancient, financier |

### 46.2.2 Dropping the Final Silent *-e*

- **Drop** the *-e* before a suffix beginning with a **vowel**: *hope → hoping, write → writing, love → lovable, come → coming, argue → arguing, desire → desirable, sense → sensible*.
- **Keep** the *-e* before a suffix beginning with a **consonant**: *hope → hopeful, care → careful, move → movement, safe → safety, sincere → sincerely, excite → excitement*.
- **Exceptions:** *argue → argument; true → truly; due → duly; whole → wholly; nine → ninth; awe → awful; judge → judgment (also judgement); acknowledge → acknowledgment (also acknowledgement)*.
- **Keep** the *-e* after soft *c / g* before *-able / -ous*: *noticeable, serviceable, changeable, manageable, knowledgeable, courageous, outrageous, advantageous*.
- **Keep** the *-e* to avoid confusion: *dyeing* (colouring) vs *dying*; *singeing* vs *singing*; *shoeing, hoeing, canoeing, being, seeing, agreeing*.

### 46.2.3 Changing *-y* to *-i*

- **Consonant + *y*** → change to ***i*** before any suffix except *-ing*: *happy → happiness, happily; beauty → beautiful; carry → carried, carriage; try → tried, tries; pity → pitiful; busy → business; lazy → laziness; merry → merriment*.
- **Keep *y*** before *-ing*: *carrying, studying, trying, flying*.
- **Vowel + *y*** keeps *y*: *play → played, player; enjoy → enjoyment; obey → obeyed; employ → employer* (exceptions: *pay → paid, lay → laid, say → said, day → daily, gay → gaily*).

### 46.2.4 Doubling the Final Consonant

Double the final consonant before a vowel suffix when **(a)** the word ends in **one vowel + one consonant**, and **(b)** the **final syllable is stressed** (or the word has one syllable):

| Double | Do not double |
|---|---|
| stop → stopped, stopping | visit → visited, visiting (stress on 1st syllable) |
| run → running, runner | open → opened, opening |
| begin → beginning, beginner | benefit → benefited |
| prefer → preferred, preferring | prefer → **preference** (stress moves to 1st syllable) |
| refer → referred, referring | refer → **reference** |
| occur → occurred, occurrence | offer → offered |
| commit → committed, committee | limit → limited |
| admit → admitted, admittance | profit → profited |
| forget → forgettable | target → targeted |
| regret → regrettable | develop → developed |
| control → controlled | focus → focused (focussed BrE also) |
| equip → equipped | worship → worshipped (BrE) / worshiped (AmE) |

British English also doubles final ***-l*** after a single vowel even when unstressed: *travel → travelled, traveller; cancel → cancelled; label → labelled; quarrel → quarrelled; model → modelled; marvel → marvellous* (American: *traveled, canceled, marvelous*).

### 46.2.5 Prefixes Do Not Change the Root

Simply add the prefix — even if it produces a **double letter**:

*mis + spell = **misspell**; mis + step = **misstep**; dis + satisfy = **dissatisfy**; dis + similar = **dissimilar**; un + necessary = **unnecessary**; un + natural = **unnatural**; il + legal = **illegal**; il + literate = **illiterate**; im + mortal = **immortal**; im + material = **immaterial**; ir + regular = **irregular**; ir + relevant = **irrelevant**; over + rule = **overrule**; inter + relate = **interrelate**; re + enter = **re-enter**.*

But: *dis + appear = **disappear*** (one *s*, one *p*); *dis + appoint = **disappoint***.

### 46.2.6 Suffix Pairs

| Pair | Guidance and examples |
|---|---|
| **-able / -ible** | *-able* after full words: *acceptable, dependable, readable, available*; *-ible* after Latin stems: *possible, visible, audible, edible, horrible, terrible, eligible, legible, incredible, permissible, responsible, sensible* |
| **-ance / -ence** | *importance, appearance, attendance, maintenance, perseverance, relevance, resistance, tolerance* / *existence, independence, occurrence, preference, reference, residence, persistence, convenience, conscience* |
| **-ant / -ent** | *assistant, attendant, brilliant, relevant, significant, pleasant* / *dependent (adj), independent, permanent, prominent, persistent, competent, consistent* |
| **-ary / -ery / -ory** | *dictionary, library, secretary, necessary, temporary, vocabulary* / *cemetery, stationery (paper), bribery, machinery* / *factory, laboratory, history, compulsory, satisfactory* |
| **-cede / -ceed / -sede** | only **supersede** ends in *-sede*; only **proceed, exceed, succeed** end in *-ceed*; all others end in *-cede*: *precede, recede, concede, intercede, secede* |
| **-ise / -ize / -yse** | BrE: *organise / organize*; always *-ise*: *advertise, advise, comprise, compromise, despise, devise, exercise, improvise, revise, supervise, surprise, televise*; *-yse* (BrE) / *-yze* (AmE): *analyse / analyze, paralyse / paralyze* |
| **-ful** | one *l*: *beautiful, careful, useful, grateful, wonderful, spoonful* (but *full*) |
| **-ly after -l** | keep both *l*'s: *usually, finally, really, carefully, accidentally, beautifully, totally* |
| **-ness after -n** | keep both *n*'s: *openness, suddenness, stubbornness, evenness, cleanness* |

## 46.3 British and American Spelling

Both are correct, but you should be **consistent**. Bangladeshi exams normally follow **British** spelling; the SAT, GRE and GMAT use **American** spelling.

|---|---|---|---|
| colour, honour, labour, favour, behaviour, neighbour | color, honor, labor, favor, behavior, neighbor | centre, theatre, metre, litre, fibre | center, theater, meter, liter, fiber |
| defence, offence, licence (n), practice (n) | defense, offense, license, practice | organise, realise, recognise (also -ize) | organize, realize, recognize |
| analyse, paralyse | analyze, paralyze | travelled, cancelled, jewellery | traveled, canceled, jewelry |
| programme (TV, plan) | program | catalogue, dialogue, analogue | catalog, dialog (computing), analog |
| cheque (bank) | check | tyre | tire |
| grey | gray | plough | plow |
| aluminium | aluminum | mould | mold |
| enrol, fulfil, skilful, instalment | enroll, fulfill, skillful, installment | judgement / judgment | judgment |
| sceptic | skeptic | manoeuvre | maneuver |
| oestrogen, foetus, paediatrics | estrogen, fetus, pediatrics | encyclopaedia (also -pedia) | encyclopedia |
| ageing | aging | storey (floor) | story |
| pyjamas | pajamas | draught | draft |
| kerb | curb | gaol (old) | jail |

## 46.6 Spelling in the SAT, GRE and GMAT

::: gre
- International tests do not test spelling directly, but **commonly confused homophones** (*its/it's, their/there/they're, affect/effect, principal/principle, complement/compliment, than/then*) are tested in **SAT Writing** as **word choice** questions.
- In the **GRE Analytical Writing** essay, occasional spelling errors are not heavily penalised, but frequent errors lower the score; use **American spelling** consistently on US tests.
- Many **GRE words** are themselves spelling traps: *acquiesce, connoisseur, idiosyncrasy, liaison, mischievous, ostentatious, perseverance, sacrilegious, supersede, vacillate, harass, embarrass, desiccate, accommodate, millennium, minuscule (✘ miniscule), restaurateur (✘ restauranteur)*.
:::
