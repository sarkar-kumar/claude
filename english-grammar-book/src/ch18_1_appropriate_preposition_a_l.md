## 18.1 Why "Appropriate Prepositions" Matter

Certain **verbs, nouns, adjectives and participles** are always followed by a **particular preposition**. There is often no logical reason for the choice — it is a matter of **usage (idiom)**. *We are **fond of** music* but *interested **in** music* and *keen **on** music*; we *depend **on*** someone but are *independent **of*** them. Such combinations must be **learnt by heart**.

"Use appropriate prepositions" is a standard question in BCS Preliminary and Written, Bank recruitment tests, university admission tests and HSC/SSC examinations, and in GMAT Sentence Correction it appears as **idiom** questions. This chapter gives:

1. words that take **different prepositions with different meanings** (the most tested items);
2. an **alphabetical master list** of words and their appropriate prepositions with examples;
3. common **prepositional phrases** (*at random, by heart, in vain …*).

::: tip
**How to learn this chapter:** (1) Read each entry aloud with its example — the ear remembers phrases better than rules. (2) Notice families: words of **feeling towards a person** often take ***with*** (*angry with, pleased with, disgusted with*) while the **thing** takes ***at*** or ***about*** (*angry at/about the delay*). (3) Notice that **related words share prepositions**: *depend on – dependent on – dependence on*; but *independent **of*** is the opposite. (4) After any preposition, a verb must be in the **-ing** form: *insist **on going**, fond **of reading***.
:::

## 18.2 Same Word, Different Prepositions, Different Meanings

| Word | Preposition and meaning | Example |
|---|---|---|
| **Agree** | *with* a person / an opinion | *I agree **with** you.* |
| | *to* a proposal / plan / suggestion | *He agreed **to** my proposal.* |
| | *on / about* a point / matter | *They agreed **on** the date.* |
| **Angry** | *with* a person | *Father was angry **with** me.* |
| | *at / about* a thing or action | *He was angry **at** the delay / **about** the result.* |
| **Annoyed** | *with* a person; *at / about* a thing | *annoyed **with** him; annoyed **at** his remarks* |
| **Anxious** | *about / for* = worried | *anxious **about** her health; anxious **for** his safety* |
| | *for* = eager to have | *anxious **for** success* |
| | *to* + verb = eager | *anxious **to** succeed* |
| **Apply** | *to* a person / authority | *Apply **to** the Principal.* |
| | *for* a thing (job, leave) | *He applied **for** the post.* |
| **Answer** | *to* a person (be answerable) | *You will answer **to** me for this.* |
| | *for* an action | *He must answer **for** his crime.* |
| **Attend** | (no prep.) = be present at | *He attended the meeting.* |
| | *to* = pay attention to / deal with | *Attend **to** your studies. The doctor attended **to** the patient.* |
| | *on / upon* = serve | *The nurse attended **on** the patient.* |
| **Call** | *on* a person = visit | *I called **on** my uncle.* |
| | *at* a place = visit | *I called **at** his house.* |
| | *for* = demand / need | *The situation calls **for** action.* |
| | *off* = cancel | *The strike was called **off**.* |
| **Compare** | *to* = liken (show similarity) | *Life is compared **to** a journey.* |
| | *with* = examine differences | *Compare your answer **with** mine.* |
| **Compensate** | *for* a loss; *by* means | *He was compensated **for** the loss.* |
| **Concerned** | *about / for* = worried | *concerned **about** the future* |
| | *with / in* = involved in, about | *The book is concerned **with** history. All those concerned **in** the crime …* |
| **Consist** | *of* = be made up of | *The book consists **of** ten chapters.* |
| | *in* = have as its essence | *Happiness consists **in** contentment.* |
| **Correspond** | *with* a person = exchange letters | *I correspond **with** my pen friend.* |
| | *to / with* a thing = match | *His words do not correspond **to** his actions.* |
| **Deal** | *in* = trade in | *He deals **in** jute.* |
| | *with* = handle / treat / be about | *Deal **with** the problem. This book deals **with** grammar.* |
| **Die** | *of* a disease | *He died **of** malaria.* |
| | *from* a cause / wound | *He died **from** overwork / a wound.* |
| | *by* violence / weapon | *He died **by** the sword / **by** his own hand.* |
| | *for* a cause / country | *Our martyrs died **for** the mother tongue.* |
| | *in* an accident / battle | *He died **in** a road accident.* |
| | *through* neglect | *The plant died **through** neglect.* |
| **Differ** | *from* = be unlike | *My views differ **from** yours.* |
| | *with* a person = disagree | *I differ **with** you on this point.* |
| **Disappointed** | *in / with* a person | *I am disappointed **in** you.* |
| | *at / about / with* a thing | *disappointed **at** the result* |
| | *of* = not getting | *disappointed **of** his hopes* |
| **Entrust** | *a person with a thing* / *a thing to a person* | *I entrusted him **with** the money. I entrusted the money **to** him.* |
| **Fight** | *with / against* an enemy | *They fought **with / against** the enemy.* |
| | *for* a cause | *We fought **for** freedom.* |
| **Glad** | *of* a thing (= grateful for) | *I would be glad **of** your help.* |
| | *about / at* news, event | *glad **about** the news* |
| **Grateful** | *to* a person | *I am grateful **to** you.* |
| | *for* a favour / thing | *I am grateful to you **for** your help.* |
| **Indebted** | *to* a person; *for* a favour | *I am indebted **to** him **for** my success.* |
| **Interfere** | *with* = hinder / meddle with a thing or person | *Don't interfere **with** my work.* |
| | *in* = intervene in affairs | *Don't interfere **in** others' affairs.* |
| **Live** | *on* food / money | *Cows live **on** grass. He lives **on** his salary.* |
| | *by* a means / work | *He lives **by** fishing.* |
| | *for* an aim | *He lives **for** his children.* |
| | *within* means | *Live **within** your means.* |
| **Look** | *at* = see, observe | *Look **at** the board.* |
| | *for* = search | *I am looking **for** my pen.* |
| | *after* = take care of | *She looks **after** her old parents.* |
| | *into* = investigate | *The police will look **into** the matter.* |
| | *forward to* = anticipate with pleasure | *I look forward **to** meeting you.* |
| | *down on / up to* = despise / respect | *Don't look down **on** the poor. We look up **to** our teachers.* |
| **Part** | *from* a person | *He parted **from** his friends.* |
| | *with* a thing | *He would not part **with** his money.* |
| **Responsible** | *to* a person / authority | *The minister is responsible **to** Parliament.* |
| | *for* a thing / action | *He is responsible **for** the loss.* |
| **Smile** | *at* = look with a smile | *She smiled **at** the baby.* |
| | *on / upon* = favour | *Fortune smiled **on** him.* |
| **Suffer** | *from* an illness / problem | *He suffers **from** asthma.* |
| | *for* one's actions | *He suffered **for** his sins.* |
| **Tired** | *of* = bored with | *I am tired **of** waiting.* |
| | *from / with* = exhausted by | *tired **from** the long walk* |
| **Warn** | *of / about* a danger | *He warned me **of** the danger.* |
| | *against* doing something | *He warned me **against** going there.* |
| **Wait** | *for* a person / thing | *Wait **for** me.* |
| | *on / upon* = serve | *The waiter waited **on** us.* |
