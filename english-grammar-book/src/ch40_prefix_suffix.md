## 40.1 Roots, Prefixes and Suffixes

Most long English words are built from smaller meaningful parts:

- **Root (base):** the core part that carries the main meaning — *port* (carry), *dict* (say), *happy*.
- **Prefix:** a part added at the **beginning** of a word; it **changes the meaning** but usually **not the part of speech** — *un**happy**, **re**write, **im**port*.
- **Suffix:** a part added at the **end** of a word; it usually **changes the part of speech** (and sometimes the meaning) — *happi**ness**, port**able**, dict**ate***.

Prefixes and suffixes together are called **affixes**.

::: ex
- *un + happy + ness* → **unhappiness** (prefix *un-* = not; suffix *-ness* = noun)
- *trans + port + ation* → **transportation** (across + carry + noun)
- *in + dict + ment* → **indictment**
- *pre + dict + able* → **predictable**
:::

Knowing affixes and roots helps you **(1)** form opposites and different parts of speech (common BCS/admission questions), **(2)** spell correctly, and **(3)** guess the meaning of **unknown words** — the single most powerful vocabulary strategy for the **GRE, SAT and GMAT**.

## 40.2 Negative Prefixes (Forming Opposites)

| Prefix | Meaning | Examples |
|---|---|---|
| **un-** | not, opposite of | unable, unhappy, unkind, unknown, unfair, unusual, untidy, unlock, undo, unveil |
| **in-** | not | inactive, incorrect, incomplete, independent, inefficient, insane, invisible, inaccurate |
| **im-** (before *b, m, p*) | not | imbalance, immature, immortal, impatient, impolite, impossible, impure, imperfect |
| **il-** (before *l*) | not | illegal, illegible, illiterate, illogical, illegitimate, illiberal |
| **ir-** (before *r*) | not | irregular, irrelevant, irresponsible, irrational, irreversible, irresistible, irreparable |
| **dis-** | not, opposite, remove | disagree, dishonest, dislike, disobey, disorder, disappear, disconnect, discomfort |
| **non-** | not | nonsense, non-violent, non-existent, non-stop, nonchalant, non-fiction |
| **mis-** | wrongly, badly | misunderstand, misuse, mislead, misbehave, misfortune, misprint, misspell |
| **mal-** | badly, ill | malfunction, malnutrition, maltreat, malpractice, malcontent, malevolent |
| **a- / an-** | without, not | amoral, atypical, apolitical, asymmetry, anarchy, anaemia, anonymous |
| **anti-** | against | antisocial, antibiotic, antiseptic, anticlockwise, antidote, antipathy |
| **counter-** | against, opposite | counteract, counterattack, counterpart, counterproductive |
| **de-** | reverse, remove, down | decode, defrost, deforestation, devalue, degrade, decentralise |
| **contra-** | against | contradict, contraband, contraception, contravene |
| **ab-** | away from | abnormal, absent, abduct, abstain |

::: note
**Which negative prefix?** There is no complete rule, but: ***im-*** before *b, m, p*; ***il-*** before *l*; ***ir-*** before *r*; ***in-*** before most other Latin-origin words; ***un-*** mostly before native English words and words ending in *-ed, -ing, -able, -ful*. Some words take two different prefixes with different meanings: *unarmed* (without weapons) vs *disarmed* (weapons taken away); *uninterested* (not interested) vs *disinterested* (impartial); *unable* vs *disable(d)*; *unorganised* (not organised yet) vs *disorganised* (badly organised).
:::

::: tip
**Careful — *in-* does not always mean "not":** *inflammable* = easily set on fire (= *flammable*); *invaluable* = extremely valuable; *inhabit* = live in; *intend, insist, include, income, inside* — here *in-* means "in, into". Similarly *ravel* and *unravel* both mean "to untangle"; *loosen* and *unloosen* mean the same.
:::

## 40.8 Spelling Rules When Adding Affixes

1. **Prefixes do not change the spelling of the root:** *un + necessary = **unn**ecessary; mis + spell = mi**ss**pell; dis + satisfy = di**ss**atisfy; il + legal = i**ll**egal; im + mortal = i**mm**ortal; ir + regular = i**rr**egular; over + run = overrun*.
2. **Drop the silent *-e* before a suffix beginning with a vowel:** *hope → hoping, love → lovable, write → writing, use → usage, fame → famous*. **Keep** it before a consonant suffix: *hope → hopeful, care → careful, move → movement* (exceptions: *argue → argument, true → truly, nine → ninth, judge → judgment* (also *judgement*), *awe → awful, whole → wholly*).
3. **Keep the *-e* after *c* or *g* before *-able / -ous*** to keep the soft sound: *notice → notic**e**able, change → chang**e**able, courage → courag**e**ous, manage → manag**e**able, outrage → outrag**e**ous*.
4. **Consonant + *y* → *i*** before most suffixes: *happy → happiness, beauty → beautiful, carry → carriage, easy → easily, pity → pitiful* (but keep *y* before *-ing*: *carrying, studying*).
5. **Double the final consonant** of a one-syllable word or a stressed final syllable before a vowel suffix: *run → runner, begin → beginning, occur → occurrence, forget → forgettable, regret → regrettable, commit → committee*. (No doubling when the stress is not final: *benefit → benefited, offer → offering*.)
6. **-able vs -ible:** *-able* usually follows a **complete word** (*accept**able**, comfort**able**, depend**able***); *-ible* usually follows a **Latin root that is not a complete word** (*poss**ible**, vis**ible**, ed**ible**, aud**ible**, terr**ible***). Exceptions exist (*flex**ible**, collect**ible***).
7. **-ance / -ence, -ant / -ent:** no fixed rule; learn by family: *import**ant** – import**ance***; *differ**ent** – differ**ence***; *independ**ent** – independ**ence***; *relev**ant** – relev**ance***; *exist**ent** – exist**ence***.
8. **-ise / -ize:** British English accepts both (*organise/organize*); American English uses *-ize*. Some words are always *-ise*: *advertise, advise, comprise, compromise, despise, devise, exercise, revise, supervise, surprise, televise*. *Analyse/paralyse* (BrE) vs *analyze/paralyze* (AmE).

## 40.9 Exam Applications

**(a) Forming opposites with prefixes:**

::: ex
- *legal → **il**legal; regular → **ir**regular; patient → **im**patient; honest → **dis**honest; understand → **mis**understand; sense → **non**sense; kind → **un**kind; possible → **im**possible; literate → **il**literate; responsible → **ir**responsible; appear → **dis**appear; fortune → **mis**fortune; function → **mal**function; violent → **non**-violent*
:::

**(b) Forming nouns/adjectives/verbs with suffixes** (full lists in Chapter 41):

::: ex
- *wide → widen (v), width (n); strong → strengthen (v), strength (n); beauty → beautify (v), beautiful (adj); able → enable (v), ability (n); real → realise (v), reality (n); simple → simplify (v), simplicity (n); danger → endanger (v), dangerous (adj)*
:::

**(c) Guessing word meaning from parts:**

::: ex
- ***circumnavigate*** = *circum* (around) + *navigate* (sail) → to sail around.
- ***benevolent*** = *bene* (good) + *vol* (wish) + *-ent* → wishing good, kind.
- ***incredulous*** = *in* (not) + *cred* (believe) + *-ulous* → not believing, sceptical.
- ***retrospective*** = *retro* (back) + *spect* (look) + *-ive* → looking back.
- ***omnivorous*** = *omni* (all) + *vor* (eat) + *-ous* → eating all kinds of food.
- ***philanthropist*** = *phil* (love) + *anthrop* (mankind) + *-ist* → a lover of mankind, one who gives to charity.
:::

## 40.10 Prefixes and Suffixes in the SAT, GRE and GMAT

::: gre
- **GRE/SAT vocabulary decoding:** When you meet an unfamiliar word in Text Completion or Reading, break it into parts: *in-defatig-able* (not + tire + able = tireless), *mal-ediction* (bad + saying = curse), *equi-voc-al* (equal + voice = ambiguous), *circum-spect* (around + look = cautious), *e-locu-tion* (out + speak = art of speaking).
- **Beware of false analysis:** roots give **clues, not proof**. *Inflammable* means *flammable*; *pedagogue* (teacher) has nothing to do with feet (*ped* here is Greek *paid* = child); *noisome* means foul-smelling, not noisy.
- **GMAT:** word-form errors (*a similarity* vs *similar*, *economic* vs *economical*) are tested indirectly; knowing suffixes helps you choose the right part of speech.
:::
